# Assignment 3 submission checklist

Repository: <https://github.com/kaonun/CSE3CWA-1>

## Code archive

- Confirm `assessment-3` and `master` point to the final tested commit.
- Run `npm ci` and `npm run check` from a clean checkout.
- Run `npm run submission:zip` only after all changes are committed.
- Open the generated archive under `submission/` and confirm it contains the
  source, migrations, tests and documentation but no `node_modules`, `.next`,
  local database, raw test reports or Git metadata.
- Upload the zip and include the repository link above.

## Video

- Keep the recording between 3 and 8 minutes.
- Show your face, voice and student ID.
- Show the Dashboard, stored/simulated data, alerts, reports and builder flow.
- Show `/health`, `/health/database` and `/health/metrics`.
- Show Playwright, JMeter and Lighthouse evidence.
- Show the GitHub homepage, branches and commit history.

## Moodle and Turnitin

- Submit the code archive and video in the locations required by the subject.
- Add the repository link wherever the submission form requests it.
- Submit the required written/cover material in a Turnitin-readable format such
  as Word or PDF.
- Wait for processing and confirm that a similarity score is generated before
  the deadline; resubmit in an accepted format if it is missing.
- Download or screenshot the final Moodle submission receipt.
